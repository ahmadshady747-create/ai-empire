# إمبراطورية الذكاء الاصطناعي — لعبة قرارات لنظام أندرويد (Flutter)

لعبة قصصية بالعربية، مستوحاة من منطق لعبة "واحد من 8 مليارات" نفسها،
لكن الرحلة هنا رحلة مؤسس: تبدأ مطورا عمره 22 عاما، وتبني نماذج
وشركات، حتى الاكتتاب أو الاستحواذ أو الإفلاس أو التقاعد.

- في كل رحلة تولد شخصية عشوائية: اسم ودولة وشركة ناشئة باسم مختلق،
  ولا يختار اللاعب شيئا من ذلك.
- تتخذ قرارات المؤسس عبر أحداث عمرية، كل خيار له نتيجة وأثر على
  سبع إحصاءات: التقنية، الروح المعنوية، البحث، المال، شبكة العلاقات،
  المهارة، والسمعة.
- تختار رؤية شركتك (هيمنة سوقية، ذكاء عام، مصدر مفتوح، ربحية
  مستدامة)، وتُقاس في نهاية مسيرتك.
- أحداث العالم سيناريوهات محاكاة مستوحاة من سياسات وتنظيمات عامة
  (قوانين تنظيم، فقاعات تمويل، حروب رقائق)، ليست بيانات رسمية
  ولا تنبؤات؛ وأرقام الدول مبسطة لأغراض اللعب.
- تعمل دون إنترنت، ولا تجمع بيانات، ولا تحتاج أي حزمة خارجية
  عدا shared_preferences للحفظ المحلي.

## الأنظمة

- 12 حدث بداية + 9 أحداث نمو، إضافة إلى 6 أحداث عالمية تتكرر
  كل بضع سنوات حسب إقليم دولتك وقوة اقتصادها.
- قصص متسلسلة: قرارك في حدث يفرض الفصل التالي (مثل قصة
  "إطلاق النموذج الكبير": ليلة الإطلاق، ثم فصل ثانٍ يختلف حسب
  اختيارك — منافس ينسخك، أو اتهام بالاحتكار، أو منافس يسبقك).
- سنوات تدبير بين الأحداث المصيرية، ووظيفة وراتب سنوي ورصيد
  نقدي يتراكم عبر السنوات.
- إنجازات تُفتح عبر المسيرة، ونقاط حياة نهائية، وسجل حياة كامل
  يمكن نسخه ومشاركته عند النهاية.
- حفظ محلي كامل للرحلة واستئنافها لاحقا.

## البنية

- `lib/models.dart` — الشخصية والإحصاءات والأحداث والخيارات.
- `lib/data/countries.dart` — الدول بملفات سياسات مبسطة.
- `lib/data/events.dart` — أحداث البداية والنمو.
- `lib/data/world_events.dart` — الأحداث العالمية.
- `lib/data/yearly_events.dart` — سنوات التدبير.
- `lib/data/arcs.dart` — القصص المتسلسلة.
- `lib/data/deep_events.dart` — أحداث عميقة (قيد التوسيع).
- `lib/game_engine.dart` — الولادة العشوائية، اختيار الأحداث،
  تطبيق القرارات، والنهايات.
- `lib/screens/` — البداية، اللعب، النهاية.
- `lib/widgets/stat_bar.dart` — شريط إحصاءة.

## التشغيل والبناء

```bash
flutter pub get
flutter run
flutter build apk --release
```

ملف APK الناتج يكون في:

```
build/app/outputs/flutter-apk/app-release.apk
```

## البناء على GitHub Actions

كل دفع إلى فرع `main` يشغّل `.github/workflows/build-apk.yml` تلقائيا:
يفحص الكود، يشغّل الاختبارات، ويبني `app-release.apk`، ثم يرفعه
كـ Artifact باسم `ai-empire-apk` في صفحة تشغيل الـ Workflow.
حمّله من هناك وثبّته على هاتف أندرويد.

## أفكار تطوير مقترحة

- نظام تدريب النماذج: حوسبة وبيانات وتكلفة، ومستوى نموذج يرتفع.
- مستثمرون وشخصيات بذاكرة وعلاقات.
- أمان وحوكمة: فريق أمان وحوادث وسياسات داخلية تؤثر على السمعة.
- نهايات مفصلة: اكتتاب واستحواذ وإفلاس، ثم اللعب بوريث
  أو مشروع تالٍ.
